# game_test

For AI agents: read AGENTS.md first.

Проект Unity 6000.3.24f1 для воссоздания игрового опыта StarCraft II.
Реализован первый экспериментальный RTS-срез: Terran-база, экономика,
строительство, армия, AI, бой, туман войны, сохранения и повторы.
Версия prototype-terran-0.3 добавляет инженерный комплекс, арсенал,
технологическое дерево [F2] и три уровня оружия/брони пехоты. Реализованы
исследования, отмена, требования, сохранение прогресса и повтор.
Windows-сборка: `Builds/Players/Windows/KopruluFront.exe`. В Unity — сцена
`Assets/Game/Scenes/Frontier.unity`. Актуальные тесты и результаты — в
[текущей итерации](docs/sc2/current-iteration.md);
полный технологический
маршрут проверен на 31 149 тиках. Итерация 04 ускоряет CPU, fog/navigation,
копирование наблюдений и rendering; simulation работает на отдельном потоке
с публикацией снимков для UI. Добавлены 24 сгенерированные графические иконки.
В оконной Release-сборке на текущем ПК, 1600×900, 4×MSAA и soft shadows,
800 патрулирующих морпехов с HUD/fog/minimap дают p95 кадра 11,41 мс при выборе
одного юнита и 14,28 мс при выборе всей армии. Симуляция сохраняет 20 Hz.
Итерация 05 проверяет настоящий бой 400 на 400: в десяти независимых Release-
прогонах p99 кадра не превышает 15,54 мс при 20 Hz, включая HUD/fog/minimap,
стрельбу и потери. Сохранены 1600×900, 4×MSAA и soft shadows. Это бюджет по
p99 для измеренного сценария, с отдельными более долгими кадрами; к тику 60
остаются 760 бойцов. Полный матч с движением и AI требует отдельных замеров.
Оптимизированы targeting, временные массивы, HUD и повторное использование
эффектов стрельбы. Полный объём SC2 остаётся в плане.
Актуальный C22: 246/246 тестов, compile 0/0 и обе Windows-сборки прошли.
C21 добавил opt-in диагностику циклов GUI-потока; C22 берёт Screen.height
один раз за Repaint в DrawWorldLabels. Обычный режим не делает новых native
cycle reads. Повторяемый FPS выигрыш C22 не установлен, строгая цель по всем
кадрам остаётся открытой. [Контракты и ограничения](docs/sc2/iteration-06.md).

Исторические результаты итерации 06 до C21–C22: начальные800 с реальным движением/боем и обычным AI;
ускорена подготовка рендера, уменьшены временные массивы observations и
пересоздания ранее наблюдавшихся моделей. C13 сохраняет native buffers полос
здоровья по фактическому пику и повторно использует неизменные индексы.
Тридцать Release-боёв C13 (50 545 кадров) прошли p95/p99/20Hz и full800/near720:
p99 до12,45 мс при одном выбранном и14,05 мс при выборе армии. Остались11кадров
дольше16,67 мс, максимум20,98 мс; кадров дольше25 мс нет. Качество сохранено.
195tests, обе builds, native/Development, Patrol и standalone regressions прошли.
Полного устранения просадок не заявляется; прежние неудачные прогоны и
локализация Gfx-ожидания приведены в текущем отчёте.
