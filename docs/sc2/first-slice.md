# Первый игровой срез Koprulu Front

Экспериментальный RTS-срез по мотивам механик StarCraft II: две Terran-базы,
добыча минералов/газа, строительство, производство армии, туман войны, AI,
бой, победа/поражение, сохранение и просмотр собственного повтора.

Обновление 21.10.2026: добавлены patrol, платный ремонт КСМ, rally на ресурс,
разнесённые конечные точки группы и улучшенное управление просмотром replay.
Ход следующей серии изменений: [итерация 02](iteration-02.md).

Версия 0.3 добавляет [технологическое дерево, оружие и броню](technology.md):
инженерный комплекс, арсенал и шесть исследований.

Числа и модели — авторский прототип; точное соответствие SC2 не заявляется.
Полная цель и оставшийся контент: [план](implementation-plan.md).
Поведение модулей: [контракт среза](../../tools/project-memory/specs/rts-first-slice.md).

## Запуск

В Unity открыть `Assets/Game/Scenes/Frontier.unity` и включить Play Mode.
В меню выбрать «Начать операцию». Для отдельного player использовать
`Builds/Players/Windows/KopruluFront.exe` после успешной сборки из runbook.
Самостоятельная сборка проходит отдельную проверку; её результат см. в
[testing](testing.md), а не только в наличии EXE.

## Управление

| Действие | Управление |
| --- | --- |
| Выбрать | ЛКМ; рамка выделяет своих мобильных юнитов |
| Добавить в выбор | Shift + ЛКМ/рамка |
| Двигаться, добывать, атаковать | ПКМ по месту, ресурсу или видимому противнику |
| Возобновить стройку | Выбранным КСМ нажать ПКМ по своему незавершённому зданию |
| Очередь приказов | Удерживать Shift при выдаче приказа |
| Атаковать по пути | A, затем ЛКМ по позиции |
| Стоп или удерживать позицию | S / H |
| Патруль | P, затем ЛКМ; Shift добавляет участок очереди |
| Ремонт | Y, затем ЛКМ по своей повреждённой технике/зданию; либо ПКМ выбранным КСМ |
| Стимулятор морпеха | T; расходует HP, повтор до завершения недоступен |
| Строительство КСМ | D — хранилище, B — казармы, R — refinery на гейзере, V — турель |
| Технологические здания | E — инженерный комплекс, U — арсенал |
| Дерево технологий | F2 или кнопка «Технологии»; Esc закрывает |
| Обучение в выбранном здании | Q: КСМ в командном центре, морпех в казармах |
| Точка сбора | ПКМ выбранным зданием; на минералы/refinery — новые КСМ начинают добычу |
| Отмена производства/стройки | X либо кнопка панели |
| Камера | Стрелки, средняя кнопка мыши, колесо; Space возвращает к базе |
| Контрольные группы | Ctrl + 1–9 записывает, 1–9 выбирает |
| Тактическая карта | ЛКМ перемещает камеру |
| Пауза и меню | Esc; сначала отменяет режим прицеливания/размещения |
| Сохранение/загрузка | F5 / F9; также доступны в меню паузы |
| Повтор | Меню паузы либо результаты; скорость 1/2/4/8 меняется кнопкой |

Начальные КСМ автоматически добывают ближайшие минералы. Постройте хранилище,
затем казармы; обучайте морпехов, разведайте карту и атакуйте базу противника.
Refinery строится на видимом гейзере; назначенные на него КСМ приносят газ.
Проверка размещения требует видимости всего footprint здания. Гибель или Stop
строителя приостанавливает работу; другой КСМ может продолжить.

Ремонт расходует ресурсы по циклам из каталога, останавливается при полном HP
или потере цели и ждёт при нехватке средств. КСМ не ремонтирует себя или морпехов.
Последний приказ патруля повторяется; если за ним есть очередь, он достигает
исходящей точки и передаёт управление следующему приказу. В replay доступны
камера, миникарта и выбор видимых юнитов; игровые команды отключены.

## Сохранения и ограничения

Обычный профиль хранит `frontier-save.json` в Unity Application.persistentDataPath.
Automation использует отдельный каталог evidence/Saves. Сохранение проверяет
версию и hash каталога. Replay принадлежит собственному формату, не SC2Replay.
Текущий каталог prototype-terran-0.3 несовместим с сохранениями 0.1/0.2: загрузка
отклонит старый hash/version. Игровой профиль автоматизация не перезаписывает.

Пока реализована одна стратегия AI, круговое зрение без высот/LOS/cloak и
ограниченный набор Terran-сущностей. Другие расы, полноценная сеть, кампании,
Co-op и Arcade остаются следующими эпиками. Работа UI подтверждается отдельно
от симуляционных тестов; статус hardware input явно указан в результатах.
