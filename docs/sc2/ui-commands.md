# Настройка команд интерфейса

Производство берёт связи `ProducerId` из `Assets/Game/Resources/rts-rules.json`.
Новый юнит у указанного производителя появляется в панели команд без новой
ветки в BattleHud или RtsInteraction. Команда проходит обычную проверку Match:
интерфейс не назначает собственные цены, требования или ограничения снабжения.

`Assets/Game/Resources/rts-ui.json` задаёт порядок зданий/юнитов, скрытые пункты
строительства и клавиши. Не перечисленные в порядке определения добавляются
после перечисленных, в порядке каталога. `HiddenBuildDefinitions` сохраняет
прежнее отсутствие командного центра в меню строительства.

Текущие клавиши: Q — первый доступный для выбранного производителя тип юнита;
B/D/R/V/E/U — казармы, хранилище, газовый завод, турель, инженерный комплекс,
арсенал. При нескольких типах производства кнопки посылают выбранный тип;
аннотацию Q получает только первый. Подпись клавиши формируется из того же
ресурса, который читает ввод. Неизвестные ID и дубли клавиш выявляются при запуске.

Переводимые строки находятся в `Assets/Game/Resources/ui-ru.json`: подписи,
статусы технологий, причины отказа, форматы стоимости/времени и боевых показателей.
В caption-значениях строительства и обучения клавишу повторять не нужно.
Для нового контента без отдельного caption используется DisplayName каталога.
Текущий интерфейс остаётся русским; выбор дополнительных языков не добавлялся.

Проверка: `tools/test-rts.ps1 -Filter UiCommandCatalogTests`; полный интеграционный
выход — новая Windows-сборка и обычный оконный smoke через `tools/run-rts-player.ps1`.
